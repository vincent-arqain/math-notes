## 题源教学要点

professors 是两个动作的共同主语；treat A as B 与 while portraying C as D 形成对照。两个 as 短语用于宾语补足，破折号只举 C 的例子；legitimate 在学术语境中指正当、可接受，不宜机械译为法律意义的合法。

## 原创英文训练

以下是本站原创训练例句，使用独立情境练习同类问题，**不是历年试题原句**。引文样式只用于展示练习文本。

> The tutor treats speed as a useful skill while describing careful checking—such as testing each step—as equally necessary.

**训练句直译**：导师把速度视为一项有用技能，同时认为仔细检查也同样必要，例如检验每一个步骤。

**训练句拆解**：并列观察 treat A as B 与 describe C as D；破折号内只举例说明 checking。

## 低词汇量读法

先用熟悉的主语、谓语和逻辑词搭骨架；暂时把不认识的具体名词记为“某人／某事”，不要因为一个生词打断整句。再把修饰语放回它对应的名词或动作，圈出否定、条件、时间与可能性。遇到 this、they、which 等词，优先寻找最近且语义通顺的先行内容。

本条练习抓手：并列观察 treat A as B 与 describe C as D；破折号内只举例说明 checking。

## 考场价值

选项如果只看到某种思想被研究，却忽略另一种思想被排除，就会错判作者批评的核心。

做完后用一句中文复述“谁对什么作出什么判断”，再检查选项是否改动了主语、范围、因果方向或观点归属。题源的历史事实与立场按试题语境理解，不据此推断今天的政策或科学结论。
