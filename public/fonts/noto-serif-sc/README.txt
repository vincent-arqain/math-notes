Variable weight axis: 200–900, verified from the bundled font metadata.
The 101 original WOFF2 subsets are unchanged.
public/fonts.css declares each subset's actual cmap coverage as unicode-range,
so browsers fetch only the character subsets needed by a page.
Screen text uses genuine 500 weight, navigation 600 and headings 700.
