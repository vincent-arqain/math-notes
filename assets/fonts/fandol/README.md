# Fandol Song

Unmodified FandolSong-Regular.otf and FandolSong-Bold.otf from the Fandol Fonts source repository:
https://github.com/Yixf-Self/fandol-fonts/tree/b93300821373d3092e378e57ae22ecb8e9082c62

License: GPL-3.0 with the font embedding exception; see COPYING.
The matching WOFF2 files in public/fonts/fandol are lossless web-font encodings of these OTF files.
The LaTeX build, screen text and browser print typography use these same font outlines.
Chinese body text and ordinary navigation use FandolSong-Regular (400);
large headings use FandolSong-Bold (700). No synthetic weight or stroke is applied.
