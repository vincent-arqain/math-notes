一轮学习的五个动作

  • 先读题：圈出写作者、对象、核心动作、必须出现的内容、词数与署名。

  • 读范文：用中文说出每段负责什么，再记英文句子；不先背孤立的难词。

  • 看模板：方括号表示必须替换的内容。先判断要填名词、动名词、动词短语还是完整句。

  • 换题练：保留段落功能，改变人物、任务、理由、例子和措施；不能只换文章里的主题词。

  • 核查：对照题目逐项打勾，再看词数、时态、单复数与拼写。大作文图中行为通常用一般现在时。

推荐的背诵顺序

小作文先背2011推荐、2014建议、2013邀请、2016服务通知、2010招募通知、2019回复六篇，再将同组其他年份作为改写练习。大作文先背2012态度、2017行动、2013选择、2016榜样、2011环保、2015手机、2010交流、2023传承八篇，再比较相邻题。这个顺序用于减少重复记忆，不代表出题概率。

难词不会时用熟词把意思说完整

  • perseverance / persistence → keep trying / not give up。词性不同，整句一起改。
  • procrastination → putting things off / delaying work。强调拖延，不能误写“休息”。
  • broaden one’s horizons → learn more about the world。表达知识范围扩大。
  • cultural inheritance → pass traditions on to young people。主动句更容易控制。
  • interpersonal communication → talking and listening to others。可自然接具体行为。
  • fulfill one’s obligations → do what one should do。再说明具体职责。

提交前只问六件事

任务都回应了吗？图中最关键的对比写对了吗？例子真的解释了观点吗？措施有没有执行者？所有方括号和备选斜杠都删掉了吗？词数与落款符合这一题吗？

本册词数按英文正文机械统计，称呼、通知标题和落款不计，缩写、数字及连字符的不同计法可能相差数词。模板是记忆和迁移的骨架，替换后仍需补足细节并重新核查字数；它不是任何题都原样适用的成品。
