题源信息

Sentence-v1 原编号：L35（经典长难句第35句）。对应 2020年考研英语阅读 Part A，Text 2，P4。P 为该篇正文自然段编号，不是 PDF 页码。来源标注用来定位原卷中的学习对象；下方训练句独立编写。

已对照所藏原卷抽样核对年份、Text、段落及上下文；复核范围见总目录。

题源教学要点

主句是平台的成功说明某种判断；which 从句补充说明 Sci-Hub，copies 后又有省略关系词的定语从句。shows 后省略宾语从句连接词 that；该宾语从句中的 ecosystem 同时承担 has lost 与 must be transformed 的主语；so that 表目的。这里复述文章论证，不评价平台使用的合法性。

原创英文训练

以下是本站原创训练例句，使用独立情境练习同类问题，不是历年试题原句。引文样式只用于展示练习文本。

The success of the repair club, which uses parts that local shops donate, shows the old system has become too costly and must change so that everyone can use it.

训练句直译：维修社团的成功表明，旧体系已经过于昂贵，必须改变，好让每个人都能使用；该社团使用当地商店捐赠的零件。

训练句拆解：shows 后的宾语从句省略 that；has become 与 must change 共用 system 作主语；so that 表目的。

低词汇量读法

先用熟悉的主语、谓语和逻辑词搭骨架；暂时把不认识的具体名词记为“某人／某事”，不要因为一个生词打断整句。再把修饰语放回它对应的名词或动作，圈出否定、条件、时间与可能性。遇到 this、they、which 等词，优先寻找最近且语义通顺的先行内容。

本条练习抓手：shows 后的宾语从句省略 that；has become 与 must change 共用 system 作主语；so that 表目的。

考场价值

抓“平台流行→现行出版制度正当性受质疑→需要改革”三步论证，勿将它读作作者主张没有著作权。

做完后用一句中文复述“谁对什么作出什么判断”，再检查选项是否改动了主语、范围、因果方向或观点归属。题源的历史事实与立场按试题语境理解，不据此推断今天的政策或科学结论。
