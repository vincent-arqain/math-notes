R02｜后置定语：分词、不定式与介词短语

名词后面很长，把分词误当谓语：识别、主干、拆解、直译、易错点与原句练习。

总导读与速查表 · 本类目录

阅读第 02 课，共 12 课。适合约 3000—4000 词汇量的学习阶段；先尝试读出“谁对谁做了什么”，再核对解析。例句沿用原讲义的原创内容；方括号仅作分析标记。

识别标志 · 找主干 · 拆解结构 · 中文直译 · 易错点 · 练习 · 参考答案

识别标志

名词后紧跟 doing、done、to do 或介词短语时，先检查它是否在说明该名词；位置只是线索，不能据此一律判定语。

Students [using apps designed for learning] need time [to think] and advice [from teachers].

找主干

Students need time and advice.（学生需要时间和建议。）

拆解结构

  1. using apps designed for learning 整体修饰 Students；学生是 use 的动作发出者。
  2. designed for learning 修饰 apps，说明应用程序“被设计用于学习”。
  3. to think 修饰 time，说明时间的用途；from teachers 修饰 advice，说明建议的来源。
  4. need 后有并列宾语 time 和 advice，不是 think 与 teachers 并列。

中文直译

使用为学习而设计的应用程序的学生，需要思考的时间和教师的建议。

易错点

本例 using 表主动、designed 表被动；全句限定谓语是 need。不能推广成“所有 -ing 都表示正在发生”或“所有 -ed 都表示被动”，必须结合具体动词和修饰关系。

练习

遮住上方解析，再做一次：把四组修饰关系写成“修饰语 → 名词”，再圈出 need 后并列的两个核心名词。

先写自己的答案，再核对参考答案。

参考答案

using … → Students；designed … → apps；to think → time；from teachers → advice。并列核心是 time 和 advice。
