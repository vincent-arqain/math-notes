## 公开引用与PDF分发的独立核查

检查的是本站网页及公开Git历史中的传播范围，不以个人学习资料可读推断可对公众分发。原卷提供的英语段落可能还涉及原始报刊文字的权利，试题身份本身未构成本次核查所需的逐篇授权。

核查的一手材料：

- [国家版权局《中华人民共和国著作权法》现行公布文本](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：第2条涉及外国作品保护；第10条区分复制、翻译、信息网络传播等权利；第24条对适当引用及课堂教学/科研使用设条件，不能把面向公众的网站等同个人学习。
- [美国版权局引用常见问题](https://www.copyright.gov/help/faq/faq-fairuse.html)与[合理使用说明](https://www.copyright.gov/fair-use/)：判断结合用途、作品、引用量与市场影响；没有固定字数、比例的统一免责线，教学或非营利身份并不自动解决全部问题。
- [Springer Nature许可申请说明](https://support.springernature.com/en/support/solutions/articles/6000085109-permissions-requests)：提供网站等再次使用情境的许可申请程序；不能从文章可访问或被考试选编推出本站取得再次发布许可。

结论是**未取得覆盖整批74段真题英文及整份既有PDF的公开分发权利证明**，而不是裁定所有短引文一律不能使用。也不宣称已经追溯和排除全部可能的权利人。
