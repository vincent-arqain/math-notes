| 检查项 | 修正或证明依据 |
| --- | --- |
| 幂级数与延拓 | 分开说明在闭区间 [-1,1] 上的一致绝对收敛，以及对 x<1 的有向积分定义；证明重合区间及两个端点的一致性。x>1 不在本文范围内。 |

| Landen | 对每个 x<1 验证 x/(x-1)<1；在零点两侧求导，以零点连续性确定同一个常数。 |
| 倍角 | 在 [-1,1] 上由绝对收敛分离奇偶项，包含端点；不向实值定义域之外使用。 |

## 数值复核（辅助证据）

使用 mpmath 1.4.1、80 位十进制工作精度，独立以积分 `-quad(log1p(-x*t)/t, [0, 0.5, 1])` 计算函数值，t=0 处以极限处理。没有用待验证的函数方程实现函数值。

- 反射参数：0.00001、0.1、0.5、0.9、0.99999。
- Landen 参数：-100、-2、-1、-0.1、0、0.1、0.9、0.999。
- 反演参数：0.001、0.1、1、2、100、1000。
- 倍角参数：-1、-0.7、0、0.7、1。
- 五个特殊值：1/2、φ⁻¹、φ⁻²、-φ⁻¹、-φ；另核对 1/4、1/3 组合式。

以上 30 组残差的最大绝对值为约 `3.374e-80`，小于核对阈值 `1e-70`。

对零点五个参数、正端点四个参数、负无穷远四个参数以及截断界的十六组参数，共 29 组余项界抽查通过。调和数级数的前 399 项与 π²/12 的差在工作精度内约为 `7.38e-81`；其解析证明见正文。样本复核是发现录入或符号错误的辅助措施，不是恒等式或余项界的证明。
